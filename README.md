# Seven Guys Pizza & Burger

Demo landing page for Seven Guys Pizza & Burger, Gujranwala.

- Single static page: `index.html` (logo embedded, no build step)
- Sections: hero, Gen Z Crown signature pizza, full menu (pizzas with Medium/Large toggle, burgers, wings & sides), value deals, 3 branches, UAN and WhatsApp ordering

## Run locally

Open `index.html` in any browser.

## Deploy

Works as-is on GitHub Pages or Vercel (static site, root directory).
